## ✨ 产品简介

**优雅的计划（elegant-plan）** 是一款极简优雅的桌面悬浮任务提示器，采用苹果风格设计理念，为工作与生活提供清晰、高效的任务管理体验。应用可长期驻留桌面，随时可见、随时可用。

---

## ✅ 核心特性

### 🎨 苹果风格设计
- 毛玻璃效果背景，视觉通透优雅  
- 圆角窗口设计，柔和自然  
- 精心调校的阴影效果，层次分明  
- 极简交互，符合现代审美  

### 📌 智能窗口管理
- **窗口置顶**：始终保持在其他窗口之上  
- **位置记忆**：自动记住窗口位置和大小  
- **半透明背景**：不遮挡桌面内容，工作娱乐两不误  

### 🚀 极致性能
- 技术栈：Go + Wails  
- 启动速度快（< 1 秒）  
- 内存占用低，长期运行无压力  
- 原生应用体验，流畅不卡顿  

### 📝 强大的任务管理
- **快速创建**：一键添加新任务  
- **直观操作**：复选框标记完成  
- **拖拽排序**：长按左侧手柄调整优先级  
- **批量管理**：删除、归档等操作更高效  

### 📦 历史归档
- **自动归档**：每天北京时间 00:00 自动归档已完成任务  
- **历史查看**：按日期查看完整历史记录  
- **灵活还原**：归档任务可随时还原回首页  
- **双层删除**：首页删除进入归档；归档删除需二次确认  

### 💾 本地数据存储
- 使用 **bbolt** 嵌入式数据库  
- 数据完全本地保存，隐私安全  
- 无需网络连接  
- 数据小、占用低，长期使用无压力

### 基本操作

#### 添加任务
点击窗口顶部 **“+ 添加任务”**，输入内容后按回车保存。

#### 完成任务
点击任务左侧 **复选框**，任务将标记为完成。

#### 删除任务
鼠标悬停任务右侧出现 **删除图标**，点击后任务移入归档（可找回）。

#### 调整顺序
长按任务左侧 **拖动手柄（≡）**，上下拖动调整优先级。

#### 查看归档
点击顶部 **历史按钮** 查看归档记录，可还原或彻底删除。

### 窗口控制
- **📌 置顶按钮**：切换窗口置顶状态  
- **➖ 最小化**：最小化到系统托盘  
- **❌ 关闭**：退出应用（也可通过托盘菜单退出）

## ❓ 常见问题（FAQ）

### 多次点击启动图标会发生什么？
如果应用已在运行，再次点击会直接显示窗口，不会重复启动。

### 删除的任务能找回吗？
可以。首页删除的任务会进入历史归档；只有在归档中再次删除才会彻底删除（需要二次确认）。

### 归档记录会占用很多空间吗？
不会。任务数据非常小，即使保存数年也只占用很少空间。

### 支持同步到云端吗？
当前版本专注本地使用，不支持云同步，以更好保护隐私。
