# 优雅的计划 - 桌面任务提示器

## 产品简介

**优雅的计划**是一款极简优雅的桌面悬浮任务提示器，采用苹果风格设计理念，为您的日常工作和生活提供清晰、高效的任务管理体验。支持 Windows

### 基本操作

#### 添加任务
点击窗口顶部的 **"+ 添加任务"** 按钮，输入任务内容，按回车键保存。

#### 完成任务
点击任务左侧的**复选框**，任务将被标记为完成状态。

#### 删除任务
将鼠标悬停在任务上，点击右侧出现的**删除图标**，任务将移入归档。

#### 调整顺序
长按任务左侧的**拖动手柄**（≡ 图标），上下拖动即可调整任务顺序。

#### 查看归档
点击顶部的**历史按钮**，查看所有归档的任务记录。归档任务可以还原或彻底删除。

### 窗口控制

- **📌 置顶按钮**：切换窗口置顶状态
- **➖ 最小化**：最小化到系统托盘
- **❌ 关闭**：退出应用（也可通过托盘菜单退出）

## 常见问题


### Q: 多次点击启动图标会发生什么？
A: 如果应用已经在运行，再次点击启动图标会直接显示窗口，不会重复启动。

### Q: 删除的任务能找回吗？
A: 可以！从首页删除的任务会进入历史归档，您可以在那里找回。只有在归档中再次删除才会彻底删除（需要二次确认）。

### Q: 归档记录会占用很多空间吗？
A: 不会。任务数据非常小，即使保存数年的记录也只占用几MB空间。

### Q: 支持同步到云端吗？
A: 当前版本专注于本地使用，不支持云同步。这样可以更好地保护您的隐私。
